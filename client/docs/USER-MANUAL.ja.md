# Stereovisor ユーザーマニュアル

[English](USER-MANUAL.md) | [简体中文](USER-MANUAL.zh-CN.md) | [한국어](USER-MANUAL.ko.md) | 日本語

Stereovisor は 1 枚の写真を、カメラで動き回れるレイヤー分けされた 2.5D シーンに
変換します。処理はすべて自分のマシン上で行われます。

このマニュアルはユーザーから見たアプリケーションを説明します。実装の詳細は
[`client/docs/README.md`](README.md) と
[`service/docs/README.md`](../../service/docs/README.md) を参照してください。

## 1. インストールと初回起動

**Windows** - `Run Stereovisor.cmd` をダブルクリックするか、
`release/Stereovisor-<バージョン>-setup.exe` をインストールしてデスクトップの
ショートカットを使用します。

**Apple Silicon macOS** - `Run Stereovisor.command` をダブルクリックするか、
`.dmg` を開いてアプリケーションフォルダーにドラッグします。

**x64 Linux** - `./Run\ Stereovisor.sh` を実行するか、`.deb` をインストールします。
AppImage は実行権限を付与してから起動できます。

初回起動では**ローカル AI の起動**画面が表示され、ローカル AI ランタイムの準備と
モデルの重みのダウンロードが行われます。5 つのプロバイダーが準備状況を報告します。

| プロバイダー | 役割 |
| --- | --- |
| ローカル AI ランタイム | モデルを実行する Python 環境 |
| セグメンテーションモデル | オブジェクトを検出して切り抜く |
| マッティングモデル | 必要に応じてカットアウトの境界を締める |
| 深度モデル | レイヤーを手前から奥へ並べる |
| インペイントモデル | 背景を描き戻す |

各項目は**準備完了**、**セットアップが必要**、**利用不可**のいずれかを示します。
必要なプロバイダーが揃うとエディターが使用できるようになります。このウィンドウは
開いたままにしてください。初回のダウンロードには数分かかることがあり、次回以降は
そのままエディターが開きます。

とりあえず試したい場合は、`Run Stereovisor Preview.cmd` / `.command` / `.sh` で
**プレビューエンジン**が起動します。サンプル専用モードで、重みのダウンロードも
AI 処理も行いません。ヘッダーのバッジには常に **ローカル AI** か
**プレビューエンジン** のどちらが動作しているかが表示されます。

Windows のパッケージに含まれるのは Electron、サービスのコード、セットアップ
スクリプトだけで、Python ランタイム・AI ライブラリ・モデルの重みは初回起動時に
取得されます。システムに Python、Git、npm を入れておく必要はありません。どちらの
Windows 形式も初回セットアップにはインターネット接続と十分な空き容量が必要で、次回
以降はダウンロード済みのものを再利用し、中断したダウンロードは次の起動で再開します。
アプリを閉じるとセットアップは停止します。このビルドは署名されていないため、初回実行時
に Windows SmartScreen が警告する場合があります。

macOS と Linux のパッケージには Python ランタイムと AI ライブラリが含まれますが、
モデルの重みは初回起動時にダウンロードされます。Linux リリースは既定で CPU 推論を
使用し、CUDA がない場合は PowerPaint で GPU を使用できないことを通知します。

## 2. 画面構成

- **左レール** - **ソース**（`画像を開く`、`サンプルシーンを使用`）、**処理フロー**の
  状態一覧、サーバーと計算処理の状態、**ローカル処理のみ**の表示。
- **中央ステージ** - **コンポジション**。画像をドラッグするとカメラが動きます。表示は
  `コンポジション全体`、`背景プレート`、`元画像` を切り替えられます。
- **右インスペクター** - **レイヤーインスペクター**。マスク確認中は`候補`、シーン構築
  後は`シーンスタック`を表示します。
- **上部アクション** - `プロジェクトを読み込む`、`リセット`、`エクスポート`、`デモ`、
  `PNG`。

## 3. 作業の流れ

**処理フロー**の一覧が 4 つの段階を示します。

1. **画像を読み込む** - `画像を開く`をクリックするか、PNG / JPEG / WebP（最大
   40 MB）をステージにドロップします。`サンプルシーンを使用`で同梱のサンプルを
   読み込めます。
2. **オブジェクトを分割** - 検出器が被写体を提案し、セグメンターが 1 つずつ切り抜き、
   深度モデルが並び順を決めます。進行状況と`処理をキャンセル`は左レールに表示されます。
3. **調整して確定** - 提案されたレイヤーを確認し、前景に属するものを確定します。
4. **シーンを構築** - 確定したカットアウトを 1 つの除去マスクにまとめ、その背後の空間を
   描き戻します。

モデルの答えは出発点であって結論ではありません。どの候補も、残す・外す・結合する・
名前を変える・境界を締める・自分で塗り直すことができます。

## 4. レイヤーの確認と編集

`候補`の各行には `ON`/`OFF` の構築状態、レイヤー名、状態バッジ（`ラフ`、`調整済み`、
`確定済み`、`追加レイヤー`）が表示されます。

**選択。** レイヤーをクリックしても構築状態は変わらず、選択されるだけです。続けて
クリックすると複数選択になり、`選択項目を切り替え`で構築状態を反転、`選択項目を結合`
でマスクを 1 つのレイヤーに統合、`クリア`で選択解除できます。結合するとそのレイヤーは
`ラフ`に戻り、再度の確定が必要になります。

**マスクの編集。** `編集`でキャンバス上にマスクブラシが開きます。

| コントロール | 用途 |
| --- | --- |
| `追加` / `消去` | ブラシモード |
| `サイズ` | ブラシの直径 |
| `境界ぼかし` | 塗った境界の柔らかさ |
| `元に戻す` / `やり直す` | ブラシ履歴をたどる |
| `リセット` | 保存済みマスクに戻す |
| `マスクを適用` | 塗った状態のまま保存 |
| `適用して調整` | 保存したうえで実際の画像の輪郭に合わせて締める |
| `キャンセル` | 編集を破棄 |

`調整`はマスクを締めるだけで、広げることはありません。塗った範囲が外側の限界です。
検出されたレイヤーの調整は元の候補の内側にとどまるため、繰り返しても隣の被写体へ
はみ出すことはありません。

**検出器が見落としたレイヤーの追加。** 構築パネルの`レイヤーを追加`（または
`領域を追加`）でブラシモードに入ります。領域を塗って確定すると、通常のレイヤーとして
追加され（選択済み・未確定）、他と同じように背景の再構築に含まれます。

**名前。** 新しいレイヤーを塗っているとき、または`編集`で既存のマスクを開いたときに、
キャンバス上部の見出しから名前を編集できます。空欄にすると次の`エリア NN`になります。

**削除。** `削除`はマスク・カットアウト・候補アセットごとレイヤーを取り除きます。

**履歴。** `元に戻す`と`やり直す`はレイヤーセット全体とマスクアセットを、削除や結合も
含めて復元します。選択ツールバーにフォーカスがあるときは `Ctrl+Z` と `Ctrl+Y` が
使えます。

**確定。** `N 個のマスクを確定`で現在の選択を前景として確定し、背景の再構築が可能に
なります。

## 5. 背景プレートの構築

`背景プレートを構築`は確定済みのカットアウトをまとめ、結合したマスクを境界の汚染を
越えるまで広げてから、隠れていた背景を描き起こします。

**ローカルインペインター** - どちらかを選びます。

| 選択肢 | 動作 |
| --- | --- |
| `Big LaMa - 構造補完` | 高速・非拡散。テクスチャや構造に向きます。 |
| `PowerPaint - 高度な全面再描画` | ノイズ除去 1.00 の完全な拡散再描画。マスク内の元ピクセルは破棄されます。オプションの高品質な重みが必要です。 |

**背景プロンプト（任意）** - 被写体の背後にあるべきものを記述します。空欄のままでも、
オプションの VLM が導入されていれば自動でプロンプトが生成されます。

`背景を再構築`で補完を実行します。`隠れた背景を再構築`は確定済みオブジェクトマスクに
加えて任意の追加ホールマスクを使います。ホールマスクは`ホールマスクを追加` /
`ホールマスクを編集`で塗り、`穴をインペイント`で埋めます。

**レイヤーインペイント**は背景ではなく 1 つのカットアウトの内側を描き直します。対象
レイヤーを選び、領域を塗り、必要なら`インペイントプロンプト`を入力して
`レイヤーをインペイント`を実行します。`アンカーを移動`と`アンカーをリセット`で
レイヤーのシーン内位置を調整できます。

インペイントステップ数は既定で 25、オプションで 5〜100 に設定できます。増やすほど
遅くなり、多くの場合は仕上がりがきれいになります。

## 6. カメラ

**パララックスリグ**がコントロールをまとめます。カメラ操作でモデルが呼ばれることは
ないため、常に軽快に動きます。

**視点**

| コントロール | 範囲 |
| --- | --- |
| `水平` | -1.00 〜 1.00 |
| `垂直` | -1.00 〜 1.00 |
| `ズーム` | 1.00x 〜 1.35x |

**シーンの奥行き**

| コントロール | 範囲 |
| --- | --- |
| `強度` | 視差移動量 0 〜 100% |
| `レイヤーを中央へ` | 中央への寄せ 0 〜 100% |
| `シーンのスケール` | 0.50x 〜 2.00x |

**レンズフォーカス**

| コントロール | 範囲 |
| --- | --- |
| `被写界深度` | ぼかし 0.0 〜 24.0 px |
| `ピントの深度` | 0 〜 100%、鮮明に保たれる面 |

`モーションをプレビュー`で自動のカメラモーションを再生し、`モーション停止`で終了、
`リセット`でリグを既定値に戻します。ステージ上で画像を直接ドラッグすることもできます。

レイヤーパネルの`深度を反転`は関係を逆にします。近いレイヤーの動きが小さくなり、
遠いレイヤーと背景が大きく動きます。設定はプロジェクトとともに保存され、書き出す
動画にも反映されます。

**レイヤーごと**に、インスペクターで`深度`、`スケール`、`フェザー`、および符号付きの
`ぼかし`補正（`自動 + 補正 = 最終` ピクセルとして表示）を調整でき、他に影響を与えずに
1 枚だけ補正できます。

## 7. 書き出し

| 操作 | 結果 |
| --- | --- |
| `PNG` | 現在のコンポジットフレームをソース解像度で出力 |
| `デモ` | 4 秒のパララックス。H.264 MP4、長辺は最大 1280 px。MP4 録画に対応しない環境では WebM にフォールバックします。 |
| `エクスポート` | 処理済みアセットと編集状態をそのまま保持する可搬な `.stereovisor` パッケージ（最大 512 MB） |
| `プロジェクトを読み込む` | パッケージを新しいワークスペースに読み込み、カメラとレイヤーの状態を復元 |

オプションの`モーション速度`、`水平振幅`、`垂直振幅`は、書き出すデモとライブの
モーションプレビューの両方に作用します。

## 8. オプション

`ファイル > オプション...`（`Ctrl+,`）。言語セレクターはヘッダーにもあります。

**外観** - `モーションを減らす`と`グラフィック効果を減らす`でジョブ中のオーバーレイと
自動モーションを無効にします。OS 側の「視差効果を減らす」設定も尊重されます。

**カメラ** - `既定のズーム`、`既定の強度`、`モーション速度`、`水平振幅`、`垂直振幅`。

**推論**

| 設定 | 効果 |
| --- | --- |
| `セグメンテーション密度` | `スパース`は大きな被写体のみ、`バランス`は一般的な小物も、`高密度`はより小さなオブジェクトまで提案します |
| `オブジェクト語彙` | カンマ区切りのラベル一覧。入力すると密度の既定ラベルより優先されます。 |
| `VLM 語彙提案を使用` | ローカルの視覚言語モデルにラベル一覧を提案させます。語彙が空のときのみ実行されます。 |
| `既定の背景方式` | どちらのインペインターを初期選択にするか |
| `インペイントステップ数` | 拡散ステップ数。既定 25、範囲 5〜100 |

**詳細設定** - `サーバーアドレス`、`サーバーアクセストークン`、
`サービスコンソールを表示`、`ジョブのポーリング間隔`。

サービスコンソールは既定で非表示です。詳細設定で有効にすると次回起動時に表示され、
エディターを閉じた後も動作を続け、以降の起動で再利用されます。停止するにはコンソール
自体を閉じてください。無効の場合、非表示のサービスはアプリが所有し、アプリと一緒に
終了します。

`保存`で未適用の変更を反映し、`キャンセル`で破棄します。

## 9. メニューとショートカット

ネイティブメニューは OS のメニュー言語ではなく、アプリで選択した言語に従います。

| メニュー | 項目 |
| --- | --- |
| `ファイル` | `オプション...`、`終了` |
| `編集` | `元に戻す`、`やり直す`、`切り取り`、`コピー`、`貼り付け`、`すべて選択` |
| `表示` | `再読み込み`、`強制再読み込み`、`開発者ツールを切り替え`、`ズームをリセット`、`ズームイン`、`ズームアウト`、`フルスクリーン切り替え` |
| `ヘルプ` | `Stereovisor について` |

| ショートカット | 動作 |
| --- | --- |
| `Ctrl+,` | オプションを開く |
| `Ctrl+Z` / `Ctrl+Y` | 選択ツールバーにフォーカスがあるとき、レイヤーセットを元に戻す / やり直す |

## 10. 別のマシンのサービスを使う

Stereovisor は通常、自分でローカルサービスを起動します。別の場所で動いているサービスを
使うには、`ファイル > オプション... > 詳細設定`の`サーバーアドレス`をそのマシンの
アドレス（例 `http://192.168.1.50:5772`）に設定し、`サーバーアクセストークン`に
そのサーバーの起動時に設定した秘密鍵を入力します。アドレスを明示すると、次回起動時に
同梱サービスが立ち上がることもなくなります。

トークンを持つ全員がそのサーバー上のすべてのプロジェクトにアクセスでき、平文の HTTP は
通信を覗く相手にトークンを露出します。信頼できるネットワークでのみ使用してください。

## 11. トラブルシューティング

| 症状 | 対処 |
| --- | --- |
| 「ローカル AI スタックがインストールされていません」と表示される | `service/scripts/setup-ai.ps1` を実行し、Stereovisor を再起動します |
| 起動画面から進まない | いずれかのプロバイダーが`セットアップが必要`または`利用不可`です。初回ダウンロード中はウィンドウを開いたままにしてください。 |
| 画像が受け付けられない | PNG / JPEG / WebP を 40 MB 以内で使用してください |
| エクスポートでプロジェクトが大きすぎると表示される | プロジェクトパッケージは 512 MB までです |
| デモが MP4 ではなく WebM で書き出される | 実行環境に MP4 レコーダーがないためで、WebM は想定されたフォールバックです |
| アプリを閉じたときにジョブが実行中だった | 次回起動時にエディターが進行状況と`キャンセル`を復元します。再読み込みでサーバー側の処理が取り消されることはありません。 |
| 初回起動でエディターが開くまで時間がかかる | Windows ではこのときランタイムとモデルの重みをダウンロードします。開いたままにしてください。中断しても次の起動で再開します。 |
| 初回実行時に Windows SmartScreen が警告する | ローカルビルドの未署名実行ファイルでは想定される動作です |
| 処理中のエフェクトが気になる | `グラフィック効果を減らす`、または`モーションを減らす`を有効にします |
| 調整したらマスクが悪化した | `元に戻す`で直前のアルファに戻せます。調整は元の候補を読むため、2 回目が 1 回目のずれを重ねることはありません。 |

## 12. プライバシー

元画像も生成されたアセットも自分のマシンに留まります。サービスにクラウドプロバイダー
アダプターはなく、ネットワークは手元にないモデルの重みを取得するためだけに使われます。
左レールの**ローカル処理のみ**の表示はこれを示すものです。また、プレビュー処理が
AI 処理として提示されることはありません。
