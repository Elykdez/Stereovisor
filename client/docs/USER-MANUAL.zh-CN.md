# Stereovisor 用户手册

[English](USER-MANUAL.md) | 简体中文 | [한국어](USER-MANUAL.ko.md) | [日本語](USER-MANUAL.ja.md)

Stereovisor 把一张照片变成可用相机穿行的分层 2.5D 场景，全部在你自己的设备上完成。

本手册描述用户实际看到的应用。实现细节参见
[`client/docs/README.md`](README.md) 和
[`service/docs/README.md`](../../service/docs/README.md)。

## 1. 安装与首次启动

**Windows** - 双击 `Run Stereovisor.cmd`，或安装
`release/Stereovisor-<版本>-setup.exe` 后使用桌面快捷方式。

**Apple Silicon macOS** - 双击 `Run Stereovisor.command`，或打开 `.dmg` 并把应用
拖到"应用程序"。

**x64 Linux** - 运行 `./Run\ Stereovisor.sh`、安装 `.deb`，或为 AppImage 添加可执行
权限后启动。

首次启动会显示**本地 AI 启动**界面，期间准备本地 AI 运行时并下载模型权重。五个
提供程序会各自报告就绪状态：

| 提供程序 | 作用 |
| --- | --- |
| 本地 AI 运行时 | 运行模型的 Python 环境 |
| 分割模型 | 找出并抠出对象 |
| 抠图模型 | 按需收紧剪切图边缘 |
| 深度模型 | 为图层排定前后顺序 |
| 修复模型 | 把背景补画回来 |

每项显示**已就绪**、**需要设置**或**不可用**。所需提供程序就绪后编辑器解锁。请保持
窗口打开；首次下载可能需要几分钟，之后的启动会直接进入编辑器。

只想先看看？`Run Stereovisor Preview.cmd` / `.command` / `.sh` 会启动**预览引擎**：仅示例
模式，不下载任何权重，也不执行 AI 处理。顶部徽标始终标明当前引擎是**本地 AI** 还是
**预览引擎**。

在 Windows 上，安装包只包含 Electron、服务代码和安装脚本；Python 运行时、AI 库和模型
权重会在首次启动时下载，无需系统级 Python、Git 或 npm。两种 Windows 发行形式在首次
安装时都需要联网并留有足够磁盘空间，之后的启动会复用已下载的内容，中断的下载会在下次
启动时续传。关闭应用即会停止安装。该构建未签名，因此 Windows SmartScreen 首次运行时
可能发出警告。

macOS 与 Linux 安装包已包含 Python 运行时和 AI 库，模型权重仍会在首次启动时下载。
Linux 发行版默认使用 CPU 推理；没有 CUDA 时会提示 PowerPaint 无法使用 GPU。

## 2. 界面布局

- **左栏** - **源图像**（`打开图像`、`使用示例场景`）、**流程**状态列表、服务器与
  计算状态，以及**仅本地处理**提示。
- **中央舞台** - **合成画面**。拖动图像即可移动相机。视图可在`完整合成画面`、
  `背景底图`和`原始图像`之间切换。
- **右侧检查器** - **图层检查器**：审阅蒙版时显示`建议`，场景构建后显示`场景堆栈`。
- **顶部操作** - `导入项目`、`重置`、`导出`、`演示`、`PNG`。

## 3. 工作流程

**流程**列表跟踪四个阶段。

1. **导入图像** - 点击`打开图像`，或把 PNG、JPEG、WebP（不超过 40 MB）拖到舞台上。
   `使用示例场景`会载入内置示例。
2. **分割对象** - 检测器提出主体，分割器逐个抠出，深度模型排定前后顺序。进度与
   `取消处理`显示在左栏。
3. **优化并确认** - 审阅建议图层，确认哪些属于前景。
4. **构建场景** - 已确认的剪切图合并为一个移除蒙版，被遮挡的空间被重新画出。

模型给出的是起点而非结论。每个建议都可以保留、丢弃、合并、重命名、收紧，或者由你
自己涂抹替换。

## 4. 审阅与编辑图层

`建议`列表中每一行都包含`开`/`关`构建状态、图层名称，以及状态标记：`粗略`、
`已优化`、`已确认`或`添加的图层`。

**选择。** 点击图层只会选中它，不改变构建状态。继续点击可形成多选，然后用
`切换所选`反转它们的构建状态、用`合并所选`把蒙版并为一个图层，或用`清除`取消选择。
合并会把该图层重置为`粗略`，需要重新确认。

**编辑蒙版。** `编辑`会在画布上打开蒙版画笔：

| 控件 | 用途 |
| --- | --- |
| `添加` / `擦除` | 画笔模式 |
| `大小` | 笔刷直径 |
| `边缘模糊` | 涂抹边缘的柔和度 |
| `撤销` / `重做` | 逐步回退笔刷历史 |
| `重置` | 恢复到已保存的蒙版 |
| `应用蒙版` | 按现状保存涂抹结果 |
| `应用并优化` | 保存并依据真实图像边缘收紧 |
| `取消` | 放弃本次编辑 |

`优化`只会收紧蒙版，绝不扩大。涂抹范围就是外边界。对检测得到的图层做优化时会保持在
该图层原始建议范围内，因此反复优化不会漂移到相邻主体上。

**补上检测器遗漏的图层。** 构建面板中的`添加图层`（或`添加区域`）会进入画笔模式。
涂抹该区域并确认，它会作为普通图层追加进来：已选中、未确认，并和其他图层一样参与
背景重建。

**命名。** 在画布上方的标题处编辑名称，涂抹新图层时或用`编辑`重新打开已有蒙版时都
可以。留空则自动命名为下一个`区域 NN`。

**删除。** `删除`会连同蒙版、剪切图和建议资源一起移除图层。

**历史。** `撤销`和`重做`会恢复完整的图层集合及其蒙版资源，包括删除与合并。选择
工具栏获得焦点时，`Ctrl+Z` 和 `Ctrl+Y` 可用。

**确认。** `确认 N 个蒙版`把当前选择锁定为前景，并启用背景重建。

## 5. 构建背景底图

`构建背景底图`会汇总已确认的剪切图，把合并后的蒙版向外扩张以越过边缘污染，然后把被
遮挡的背景补画出来。

**本地修补器** - 二选一：

| 选项 | 行为 |
| --- | --- |
| `Big LaMa - 结构填充` | 快速、非扩散。适合纹理与结构。 |
| `PowerPaint - 高级完整重绘` | 去噪强度 1.00 的完整扩散重绘，原蒙版内像素将被丢弃。需要可选的高质量权重。 |

**背景提示词（可选）** - 描述主体背后应有的内容。留空时，若已安装可选的 VLM，会自动
生成提示词。

`重新构建背景`执行填充。`重建隐藏背景`使用已确认的对象蒙版加上可选的额外孔洞蒙版，
后者用`添加孔洞蒙版` / `编辑孔洞蒙版`涂抹，再用`修补孔洞`填充。

**图层修补**针对单个剪切图内部而非背景重绘。选定当前图层、涂抹区域、按需填写
`修补提示词`，然后执行`修补图层`。`移动锚点`和`重置锚点`用于调整图层在场景中的位置。

修复步数默认为 25，可在"选项"中设为 5 到 100。步数越多越慢，通常也更干净。

## 6. 相机

**视差相机架**对控件分组。相机运动不会调用任何模型，因此始终保持流畅。

**视图**

| 控件 | 范围 |
| --- | --- |
| `水平` | -1.00 至 1.00 |
| `垂直` | -1.00 至 1.00 |
| `缩放` | 1.00x 至 1.35x |

**场景深度**

| 控件 | 范围 |
| --- | --- |
| `强度` | 视差位移 0 至 100% |
| `居中图层` | 向中心收拢 0 至 100% |
| `场景缩放` | 0.50x 至 2.00x |

**镜头焦点**

| 控件 | 范围 |
| --- | --- |
| `景深` | 0.0 至 24.0 px 模糊 |
| `对焦深度` | 0 至 100%，保持清晰的平面 |

`预览运动`播放自动镜头运动，`停止运动`结束，`重置`把相机架恢复为默认值。也可以直接
在舞台上拖动图像。

图层面板中的`反转深度`会反转这一关系：较近的图层移动更少，较远的图层和背景移动更多。
该设置随项目保存，并作用于导出的视频。

**逐图层**可在检查器中调节`深度`、`缩放`、`羽化`，以及带符号的`模糊`偏移，显示为
`自动 + 偏移 = 最终`（像素），从而单独校正某一图层而不影响其余图层。

## 7. 导出

| 操作 | 结果 |
| --- | --- |
| `PNG` | 当前合成帧，保持源分辨率 |
| `演示` | 四秒视差运动，H.264 MP4，最长边不超过 1280 px。运行环境不支持 MP4 录制时回退为 WebM。 |
| `导出` | 可移植的 `.stereovisor` 包，包含全部已处理资源和精确的编辑器状态，上限 512 MB |
| `导入项目` | 把包载入全新工作区，并恢复相机与图层状态 |

"选项"中的`运动速度`、`水平幅度`和`垂直幅度`同时作用于导出的演示视频和实时运动预览。

## 8. 选项

`文件 > 选项...`（`Ctrl+,`）。语言选择器在顶部也有一份。

**外观** - `减少动效`和`减少图形效果`会关闭任务叠加效果与自动运动。系统层面的"减少
动态效果"偏好同样会被遵循。

**相机** - `默认缩放`、`默认强度`、`运动速度`、`水平幅度`、`垂直幅度`。

**推理**

| 设置 | 作用 |
| --- | --- |
| `分割密度` | `稀疏`只保留大的主体，`平衡`会加入常见场景道具，`密集`会提出更小的对象 |
| `对象词汇` | 逗号分隔的标签列表。填写任意内容即覆盖该密度的内置标签。 |
| `使用 VLM 词汇建议器` | 让本地视觉语言模型建议标签列表。仅在词汇为空时运行。 |
| `默认背景方法` | 预选哪个修补器 |
| `修复步数` | 扩散步数，默认 25，范围 5 至 100 |

**高级** - `服务器地址`、`服务器访问令牌`、`显示服务控制台`、`任务轮询间隔`。

服务控制台默认隐藏。在"高级"中启用后于下次启动出现，编辑器关闭后仍继续运行并被后续
启动复用；要停止它请直接关闭该控制台窗口。该选项关闭时，隐藏的服务由应用拥有，并随
应用一起结束。

`保存`应用待定修改，`取消`丢弃它们。

## 9. 菜单与快捷键

原生菜单跟随应用内选择的语言，而不是操作系统的菜单语言。

| 菜单 | 条目 |
| --- | --- |
| `文件` | `选项...`、`退出` |
| `编辑` | `撤销`、`重做`、`剪切`、`复制`、`粘贴`、`全选` |
| `视图` | `重新加载`、`强制重新加载`、`切换开发者工具`、`重置缩放`、`放大`、`缩小`、`切换全屏` |
| `帮助` | `关于 Stereovisor` |

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl+,` | 打开选项 |
| `Ctrl+Z` / `Ctrl+Y` | 选择工具栏获得焦点时，撤销 / 重做图层集合 |

## 10. 连接其他机器上的服务

Stereovisor 通常会启动自己的本地服务。要改用运行在别处的服务，请在
`文件 > 选项... > 高级`中把`服务器地址`设为那台机器的地址，例如
`http://192.168.1.50:5772`，并把`服务器访问令牌`设为该服务器启动时使用的密钥。显式
填写地址后，应用在下次启动时也不会再启动自带服务。

持有该令牌的任何人都能访问该服务器上的全部项目，而明文 HTTP 会把令牌暴露给任何监听
流量的人。请仅在可信网络中使用。

## 11. 故障排查

| 现象 | 处理方式 |
| --- | --- |
| 提示"本地 AI 堆栈尚未安装" | 运行 `service/scripts/setup-ai.ps1`，然后重启 Stereovisor |
| 编辑器一直停在启动界面 | 仍有提供程序处于`需要设置`或`不可用`。首次下载期间请保持窗口打开。 |
| 图像被拒绝 | 请使用 PNG、JPEG 或 WebP，且不超过 40 MB |
| 导出提示项目过大 | 项目包上限为 512 MB |
| 演示导出成 WebM 而不是 MP4 | 当前运行环境没有 MP4 录制器，WebM 是预期的回退格式 |
| 关闭应用时任务仍在运行 | 下次启动时编辑器会恢复该任务的进度和`取消`控件。重新加载绝不会取消服务器端的工作。 |
| 首次启动很久才进入编辑器 | 在 Windows 上，运行时和模型权重是此时下载的。请保持打开；中断的下载会在下次启动时续传。 |
| 首次运行时 Windows SmartScreen 警告 | 本地构建且未签名，属预期现象 |
| 处理特效干扰观察 | 开启`减少图形效果`，或`减少动效` |
| 优化后蒙版反而变差 | `撤销`可恢复上一版 alpha。优化读取的是原始建议，因此第二次不会叠加第一次的偏差。 |

## 12. 隐私

源图像和生成的资源都留在你的设备上。服务没有任何云服务商适配器，网络仅用于获取本地
尚不存在的模型权重。左栏的**仅本地处理**提示即反映这一点，预览处理也绝不会被表述为
AI 处理。
