# Stereovisor 사용 설명서

[English](USER-MANUAL.md) | [简体中文](USER-MANUAL.zh-CN.md) | 한국어 | [日本語](USER-MANUAL.ja.md)

Stereovisor는 사진 한 장을 카메라로 움직일 수 있는 레이어 기반 2.5D 장면으로
만듭니다. 모든 처리는 사용자의 기기 안에서 이뤄집니다.

이 문서는 사용자가 보는 애플리케이션을 설명합니다. 구현 세부 사항은
[`client/docs/README.md`](README.md)와
[`service/docs/README.md`](../../service/docs/README.md)를 참고하세요.

## 1. 설치 및 첫 실행

**Windows** - `Run Stereovisor.cmd`를 더블클릭하거나,
`release/Stereovisor-<버전>-setup.exe`를 설치한 뒤 바탕화면 바로가기를 사용합니다.

**Apple Silicon macOS** - `Run Stereovisor.command`를 더블클릭하거나, `.dmg`를 열어
앱을 응용 프로그램 폴더로 드래그합니다.

첫 실행에서는 **로컬 AI 시작** 화면이 나타나며 로컬 AI 런타임을 준비하고 모델
가중치를 내려받습니다. 다섯 개의 제공업체가 준비 상태를 보고합니다.

| 제공업체 | 역할 |
| --- | --- |
| 로컬 AI 런타임 | 모델이 실행되는 Python 환경 |
| 세그먼테이션 모델 | 오브젝트를 찾아 잘라냅니다 |
| 매팅 모델 | 요청 시 컷아웃 가장자리를 다듬습니다 |
| 깊이 모델 | 레이어를 앞뒤 순서로 정렬합니다 |
| 인페인팅 모델 | 배경을 다시 그려 넣습니다 |

각 항목은 **준비 완료**, **설정 필요**, **사용할 수 없음** 중 하나를 표시합니다.
필수 제공업체가 준비되면 편집기가 활성화됩니다. 창은 열어 두세요. 첫 다운로드는 몇 분
걸릴 수 있으며, 이후 실행은 곧바로 편집기로 진입합니다.

둘러보기만 하려면 `Run Stereovisor Preview.cmd` / `.command`로 **미리보기 엔진**을
실행하세요. 샘플 전용 모드로, 가중치를 내려받지 않고 AI 처리도 하지 않습니다. 헤더의
배지는 현재 엔진이 **로컬 AI**인지 **미리보기 엔진**인지 항상 알려 줍니다.

Windows 패키지에는 Electron, 서비스 코드, 설치 스크립트만 들어 있으며 Python 런타임,
AI 라이브러리, 모델 가중치는 첫 실행 때 내려받습니다. 시스템에 Python, Git, npm을
설치해 둘 필요는 없습니다. 두 Windows 배포 형태 모두 첫 설치에는 인터넷 연결과 충분한
디스크 공간이 필요하고, 이후 실행은 내려받은 내용을 재사용하며, 중단된 다운로드는 다음
실행에서 이어집니다. 앱을 닫으면 설치가 중단됩니다. 이 빌드는 서명되지 않았으므로 첫
실행 시 Windows SmartScreen 경고가 나타날 수 있습니다.

## 2. 화면 구성

- **왼쪽 레일** - **소스**(`이미지 열기`, `샘플 장면 사용`), **작업 흐름** 상태 목록,
  서버 및 연산 상태, **로컬 전용** 안내.
- **가운데 스테이지** - **컴포지션**. 이미지를 드래그하면 카메라가 움직입니다. 보기는
  `전체 컴포지션`, `배경 플레이트`, `원본 이미지` 사이에서 전환됩니다.
- **오른쪽 인스펙터** - **레이어 인스펙터**. 마스크를 검토할 때는 `제안`, 장면을 구성한
  뒤에는 `장면 스택`을 표시합니다.
- **상단 작업** - `프로젝트 가져오기`, `초기화`, `내보내기`, `데모`, `PNG`.

## 3. 작업 흐름

**작업 흐름** 목록은 네 단계를 보여 줍니다.

1. **이미지 가져오기** - `이미지 열기`를 클릭하거나 PNG, JPEG, WebP 파일(최대 40 MB)을
   스테이지에 놓습니다. `샘플 장면 사용`은 내장 예제를 불러옵니다.
2. **오브젝트 분할** - 검출기가 피사체를 제안하고, 분할기가 하나씩 잘라내며, 깊이
   모델이 순서를 정합니다. 진행 상황과 `처리 취소`는 왼쪽 레일에 표시됩니다.
3. **다듬기 및 확인** - 제안된 레이어를 검토하고 전경에 속하는 것을 확인합니다.
4. **장면 구성** - 확인된 컷아웃을 하나의 제거 마스크로 합치고, 그 뒤에 가려져 있던
   공간을 다시 그립니다.

모델의 답은 결론이 아니라 출발점입니다. 모든 제안은 유지, 제외, 병합, 이름 변경,
가장자리 다듬기가 가능하며 직접 칠해서 대체할 수도 있습니다.

## 4. 레이어 검토 및 편집

`제안` 목록의 각 행에는 `켜짐`/`꺼짐` 구성 상태, 레이어 이름, 상태 배지(`러프`,
`다듬어짐`, `확인됨`, `추가된 레이어`)가 표시됩니다.

**선택.** 레이어를 클릭하면 구성 상태는 그대로인 채 선택만 됩니다. 계속 클릭해 여러
개를 선택한 뒤 `선택 항목 전환`으로 구성 상태를 반전하거나, `선택 항목 병합`으로
마스크를 하나의 레이어로 합치거나, `지우기`로 선택을 해제할 수 있습니다. 병합하면 해당
레이어는 `러프`로 돌아가며 다시 확인해야 합니다.

**마스크 편집.** `편집`을 누르면 캔버스 위에 마스크 브러시가 열립니다.

| 컨트롤 | 용도 |
| --- | --- |
| `추가` / `지우기` | 브러시 모드 |
| `크기` | 브러시 지름 |
| `가장자리 흐림` | 칠한 가장자리의 부드러움 |
| `실행 취소` / `다시 실행` | 브러시 기록을 오갑니다 |
| `초기화` | 저장된 마스크로 되돌립니다 |
| `마스크 적용` | 칠한 그대로 저장합니다 |
| `적용 후 다듬기` | 저장한 뒤 실제 이미지 경계에 맞춰 조입니다 |
| `취소` | 편집을 버립니다 |

`다듬기`는 마스크를 조일 뿐 넓히지 않습니다. 칠한 영역이 바깥 한계입니다. 검출된
레이어를 다듬을 때는 원래 제안 범위 안에 머무르므로, 여러 번 반복해도 옆 피사체로
번지지 않습니다.

**검출기가 놓친 레이어 추가.** 구성 패널의 `레이어 추가`(또는 `영역 추가`)를 누르면
브러시 모드로 들어갑니다. 영역을 칠하고 확정하면 일반 레이어로 추가되며(선택됨,
미확인 상태) 다른 레이어와 똑같이 배경 재구성에 포함됩니다.

**이름.** 새 레이어를 칠하는 중이거나 `편집`으로 기존 마스크를 다시 연 상태에서 캔버스
위쪽 제목을 수정하면 됩니다. 비워 두면 다음 `영역 NN`이 됩니다.

**삭제.** `삭제`는 마스크, 컷아웃, 제안 자산까지 함께 레이어를 제거합니다.

**기록.** `실행 취소`와 `다시 실행`은 삭제와 병합을 포함해 전체 레이어 집합과 마스크
자산을 복원합니다. 선택 도구 모음에 포커스가 있을 때 `Ctrl+Z`와 `Ctrl+Y`를 쓸 수
있습니다.

**확인.** `마스크 N개 확인`은 현재 선택을 전경으로 고정하고 배경 재구성을 활성화합니다.

## 5. 배경 플레이트 구성

`배경 플레이트 구성`은 확인된 컷아웃을 모으고, 합친 마스크를 가장자리 오염을 넘어설
만큼 확장한 뒤 가려져 있던 배경을 그려 넣습니다.

**로컬 인페인터** - 둘 중 하나를 고릅니다.

| 선택지 | 동작 |
| --- | --- |
| `Big LaMa - 구조 채우기` | 빠른 비확산 방식. 질감과 구조에 적합합니다. |
| `PowerPaint - 고급 전체 다시 그리기` | 노이즈 제거 1.00의 완전한 확산 재생성. 마스크 안의 원본 픽셀은 삭제됩니다. 선택 설치형 고품질 가중치가 필요합니다. |

**배경 프롬프트(선택 사항)** - 피사체 뒤에 무엇이 있어야 하는지 적습니다. 비워 두면
선택 설치형 VLM이 있을 때 프롬프트가 자동으로 생성됩니다.

`배경 재구성`이 채우기를 실행합니다. `가려진 배경 재구성`은 확인된 오브젝트 마스크와
선택적 추가 홀 마스크를 함께 사용합니다. 홀 마스크는 `홀 마스크 추가` /
`홀 마스크 편집`으로 칠하고 `홀 인페인트`로 채웁니다.

**레이어 인페인트**는 배경이 아니라 하나의 컷아웃 안쪽을 다시 그립니다. 대상 레이어를
고르고 영역을 칠한 뒤 필요하면 `인페인트 프롬프트`를 입력하고 `레이어 인페인트`를
실행합니다. `앵커 이동`과 `앵커 초기화`로 장면 안에서 레이어 위치를 조정합니다.

인페인팅 단계는 기본 25이며 옵션에서 5에서 100 사이로 설정할 수 있습니다. 단계가
많을수록 느려지고 대체로 결과가 깔끔해집니다.

## 6. 카메라

**패럴랙스 리그**가 컨트롤을 묶어 줍니다. 카메라 움직임은 모델을 호출하지 않으므로
항상 부드럽게 반응합니다.

**보기**

| 컨트롤 | 범위 |
| --- | --- |
| `수평` | -1.00 ~ 1.00 |
| `수직` | -1.00 ~ 1.00 |
| `확대/축소` | 1.00x ~ 1.35x |

**장면 깊이**

| 컨트롤 | 범위 |
| --- | --- |
| `강도` | 시차 이동량 0 ~ 100% |
| `레이어 중앙 정렬` | 중앙으로 당기는 정도 0 ~ 100% |
| `장면 크기` | 0.50x ~ 2.00x |

**렌즈 초점**

| 컨트롤 | 범위 |
| --- | --- |
| `피사계 심도` | 흐림 0.0 ~ 24.0 px |
| `초점 깊이` | 0 ~ 100%, 선명하게 유지되는 평면 |

`모션 미리보기`로 자동 카메라 움직임을 재생하고, `모션 중지`로 끝내며, `초기화`로
리그를 기본값으로 되돌립니다. 스테이지에서 이미지를 직접 드래그할 수도 있습니다.

레이어 패널의 `깊이 반전`은 관계를 뒤집습니다. 가까운 레이어는 덜 움직이고 먼 레이어와
배경은 더 크게 움직입니다. 이 설정은 프로젝트와 함께 저장되며 내보낸 동영상에도
적용됩니다.

**레이어별**로 인스펙터에서 `깊이`, `크기`, `페더`, 부호가 있는 `블러` 보정을 조정할 수
있습니다. 보정값은 `자동 + 보정 = 최종` 픽셀로 표시되어, 나머지를 건드리지 않고 한
레이어만 손볼 수 있습니다.

## 7. 내보내기

| 작업 | 결과 |
| --- | --- |
| `PNG` | 현재 합성 프레임을 원본 해상도로 저장 |
| `데모` | 4초 분량의 시차 영상. H.264 MP4, 긴 변 최대 1280 px. MP4 녹화를 지원하지 않는 런타임에서는 WebM으로 대체됩니다. |
| `내보내기` | 처리된 모든 자산과 편집기 상태를 담은 이식 가능한 `.stereovisor` 패키지(최대 512 MB) |
| `프로젝트 가져오기` | 패키지를 새 작업 공간으로 불러오고 카메라와 레이어 상태를 복원 |

옵션의 `모션 속도`, `가로 범위`, `세로 범위`는 내보내는 데모와 실시간 모션 미리보기
모두에 적용됩니다.

## 8. 옵션

`파일 > 옵션...`(`Ctrl+,`). 언어 선택기는 헤더에도 있습니다.

**모양** - `모션 줄이기`와 `그래픽 효과 줄이기`는 작업 중 오버레이와 자동 움직임을
끕니다. 운영체제의 모션 줄이기 설정도 함께 반영됩니다.

**카메라** - `기본 확대/축소`, `기본 강도`, `모션 속도`, `가로 범위`, `세로 범위`.

**추론**

| 설정 | 효과 |
| --- | --- |
| `세그먼테이션 밀도` | `희소`는 큰 피사체만, `균형`은 일반적인 소품까지, `고밀도`는 더 작은 오브젝트까지 제안합니다 |
| `오브젝트 어휘` | 쉼표로 구분한 라벨 목록. 입력하면 밀도의 기본 라벨을 대체합니다. |
| `VLM 어휘 제안 사용` | 로컬 비전-언어 모델이 라벨 목록을 제안하게 합니다. 어휘가 비어 있을 때만 실행됩니다. |
| `기본 배경 방식` | 어느 인페인터를 기본 선택할지 |
| `인페인팅 단계` | 확산 단계 수. 기본 25, 범위 5~100 |

**고급** - `서버 주소`, `서버 액세스 토큰`, `서비스 콘솔 표시`, `작업 폴링 간격`.

서비스 콘솔은 기본적으로 숨겨져 있습니다. 고급에서 켜면 다음 실행부터 나타나고, 편집기를
닫은 뒤에도 계속 실행되며 이후 실행에서 재사용됩니다. 중지하려면 콘솔 창을 직접
닫으세요. 이 옵션이 꺼져 있으면 숨겨진 서비스는 앱이 소유하며 앱과 함께 종료됩니다.

`저장`은 보류 중인 변경을 적용하고 `취소`는 버립니다.

## 9. 메뉴와 단축키

네이티브 메뉴는 운영체제의 메뉴 언어가 아니라 앱에서 선택한 언어를 따릅니다.

| 메뉴 | 항목 |
| --- | --- |
| `파일` | `옵션...`, `종료` |
| `편집` | `실행 취소`, `다시 실행`, `잘라내기`, `복사`, `붙여넣기`, `모두 선택` |
| `보기` | `새로 고침`, `강제 새로 고침`, `개발자 도구 전환`, `확대/축소 재설정`, `확대`, `축소`, `전체 화면 전환` |
| `도움말` | `Stereovisor 정보` |

| 단축키 | 동작 |
| --- | --- |
| `Ctrl+,` | 옵션 열기 |
| `Ctrl+Z` / `Ctrl+Y` | 선택 도구 모음에 포커스가 있을 때 레이어 집합 실행 취소 / 다시 실행 |

## 10. 다른 기기의 서비스 사용하기

Stereovisor는 보통 자체 로컬 서비스를 시작합니다. 다른 곳에서 실행 중인 서비스를
사용하려면 `파일 > 옵션... > 고급`의 `서버 주소`를 해당 기기 주소(예:
`http://192.168.1.50:5772`)로 설정하고, `서버 액세스 토큰`에 그 서버를 시작할 때 사용한
비밀 값을 입력합니다. 주소를 명시하면 다음 실행에서 앱이 내장 서비스를 시작하지도
않습니다.

토큰을 가진 사람은 누구나 그 서버의 모든 프로젝트에 접근할 수 있고, 일반 HTTP는 트래픽을
들여다보는 사람에게 토큰을 노출합니다. 신뢰할 수 있는 네트워크에서만 사용하세요.

## 11. 문제 해결

| 증상 | 조치 |
| --- | --- |
| "로컬 AI 스택이 설치되지 않았습니다" 표시 | `service/scripts/setup-ai.ps1`을 실행한 다음 Stereovisor를 다시 시작합니다 |
| 시작 화면에서 넘어가지 않음 | 일부 제공업체가 아직 `설정 필요` 또는 `사용할 수 없음` 상태입니다. 첫 다운로드 동안 창을 열어 두세요. |
| 이미지가 거부됨 | PNG, JPEG 또는 WebP를 40 MB 이하로 사용하세요 |
| 내보내기에서 프로젝트가 너무 크다고 표시됨 | 프로젝트 패키지는 최대 512 MB입니다 |
| 데모가 MP4가 아니라 WebM으로 저장됨 | 런타임에 MP4 녹화기가 없어서이며, WebM이 의도된 대체 형식입니다 |
| 앱을 닫을 때 작업이 실행 중이었음 | 다음 실행에서 편집기가 진행 상황과 `취소`를 복원합니다. 새로 고침이 서버 작업을 취소하지는 않습니다. |
| 첫 실행에서 편집기가 열리기까지 오래 걸림 | Windows에서는 이때 런타임과 모델 가중치를 내려받습니다. 창을 열어 두세요. 중단된 다운로드는 다음 실행에서 이어집니다. |
| 첫 실행 시 Windows SmartScreen 경고 | 로컬에서 만든 미서명 실행 파일에서는 정상입니다 |
| 처리 효과가 거슬림 | `그래픽 효과 줄이기` 또는 `모션 줄이기`를 켜세요 |
| 다듬은 뒤 마스크가 더 나빠짐 | `실행 취소`로 이전 알파를 복원합니다. 다듬기는 원래 제안을 읽으므로 두 번째 시도가 첫 번째 오차를 누적하지 않습니다. |

## 12. 개인정보

원본 이미지와 생성된 자산은 사용자 기기에 남습니다. 서비스에는 클라우드 제공업체
어댑터가 없으며, 네트워크는 아직 없는 모델 가중치를 받을 때만 사용됩니다. 왼쪽 레일의
**로컬 전용** 표시가 이를 나타내며, 미리보기 처리를 AI 처리인 것처럼 표시하지도
않습니다.
